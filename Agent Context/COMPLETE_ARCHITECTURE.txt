PROBLEM STATEMENT:
Build a full-stack RAG (Retrieval-Augmented Generation) application that:
- Allows users to upload documents and index them semantically
- Provides a chat interface for natural language search queries
- Retrieves relevant content and generates grounded answers with citations
- Exposes search capability via MCP (Model Context Protocol) server
- Enforces authentication and role-based access control
- Tracks ingestion progress and search analytics

KEY FEATURES (MUST-HAVE):
- Semantic search via vector similarity
- RAG with proper citations and grounding rules
- Chat page for end users
- Admin dashboard for document management and analytics
- Role-based access control (User vs Admin)
- MCP server for external tool integration
- Production-grade error handling and logging

SCOPE TARGETS:
- Achievable in ~2 days of focused development
- Works end-to-end on fresh machine
- Type-safe TypeScript throughout
- Responsive design (mobile, tablet, desktop)

4. DATABASE LAYER
================================================================================

DATABASE CHOICE RATIONALE:
PostgreSQL + pgvector (single database):
✓ ACID compliance and reliability
✓ Native vector support via pgvector extension
✓ Supports hybrid search (keyword + vector)
✓ Cost-effective (no separate vector DB service)
✓ Easy deployment and backup
✓ Strong ecosystem for Node.js (Drizzle, TypeORM)

Alternative options (if needed):
- Qdrant: Self-hosted or cloud, specialized vector DB
- Pinecone: Fully managed, higher cost but less ops
- Milvus: Open-source distributed vector DB

ORM CHOICE: Drizzle
✓ Type-safe SQL queries
✓ Migrations built-in, stored as TypeScript
✓ Lightweight (unlike TypeORM)
✓ Zero-runtime overhead
✓ Great DX for schema definition

import { pgTable, text, uuid, timestamp, integer, boolean, jsonb, uniqueIndex } from 'drizzle-orm/pg-core';
import { sql } from 'drizzle-orm';
import { relations } from 'drizzle-orm';

// ============= USERS TABLE =============
export const users = pgTable('users', {
  id: uuid('id').primaryKey().defaultRandom(),
  email: text('email').notNull().unique(),
  hashedPassword: text('hashed_password').notNull(),
  name: text('name').notNull(),
  role: text('role').notNull().default('user'), // 'user' | 'admin'
  isActive: boolean('is_active').notNull().default(true),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
}, (table) => ({
  emailIdx: uniqueIndex().on(table.email),
}));

// ============= SESSIONS TABLE (JWT Refresh Tokens) =============
export const sessions = pgTable('sessions', {
  id: uuid('id').primaryKey().defaultRandom(),
  userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  refreshToken: text('refresh_token').notNull().unique(),
  expiresAt: timestamp('expires_at', { withTimezone: true }).notNull(),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
}, (table) => ({
  userIdIdx: uniqueIndex().on(table.userId),
}));

// ============= DOCUMENTS TABLE =============
export const documents = pgTable('documents', {
  id: uuid('id').primaryKey().defaultRandom(),
  title: text('title').notNull(),
  filename: text('filename').notNull(),
  fileType: text('file_type').notNull(), // 'pdf' | 'txt' | 'markdown'
  fileSize: integer('file_size').notNull(), // bytes
  checksum: text('checksum').notNull().unique(), // SHA-256 for duplicate detection
  uploadedBy: uuid('uploaded_by').notNull().references(() => users.id, { onDelete: 'set null' }),
  uploadedAt: timestamp('uploaded_at', { withTimezone: true }).notNull().defaultNow(),
  status: text('status').notNull().default('uploaded'), // 'uploaded' | 'processing' | 'indexed' | 'failed'
  errorMessage: text('error_message'),
  retryCount: integer('retry_count').notNull().default(0),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
}, (table) => ({
  checksumIdx: uniqueIndex().on(table.checksum),
  statusIdx: uniqueIndex().on(table.status),
}));

// ============= DOCUMENT CHUNKS TABLE =============
export const documentChunks = pgTable('document_chunks', {
  id: uuid('id').primaryKey().defaultRandom(),
  documentId: uuid('document_id').notNull().references(() => documents.id, { onDelete: 'cascade' }),
  chunkIndex: integer('chunk_index').notNull(), // Sequential order
  content: text('content').notNull(), // Actual text
  tokens: integer('tokens').notNull(), // Token count estimate
  startPosition: integer('start_position'), // Position in original file
  endPosition: integer('end_position'),
  metadata: jsonb('metadata'), // { pageNumber, section, heading, etc }
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
}, (table) => ({
  documentIdIdx: uniqueIndex().on(table.documentId),
  chunkIndexIdx: uniqueIndex().on(table.documentId, table.chunkIndex),
}));

// ============= EMBEDDINGS TABLE (Vector References) =============
export const embeddings = pgTable('embeddings', {
  id: uuid('id').primaryKey().defaultRandom(),
  chunkId: uuid('chunk_id').notNull().references(() => documentChunks.id, { onDelete: 'cascade' }).unique(),
  embedding: sql`vector(1536)`, // OpenAI text-embedding-3-small
  modelName: text('model_name').notNull(), // 'text-embedding-3-small', 'ollama/nomic-embed-text'
  modelVersion: text('model_version').notNull(), // Version tracking for future migrations
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
}, (table) => ({
  chunkIdIdx: uniqueIndex().on(table.chunkId),
  embeddingIdx: sql`CREATE INDEX embeddings_embedding_idx ON embeddings USING hnsw (embedding vector_cosine_ops)`,
}));

// ============= INGESTION JOBS TABLE =============
export const ingestionJobs = pgTable('ingestion_jobs', {
  id: uuid('id').primaryKey().defaultRandom(),
  documentId: uuid('document_id').notNull().references(() => documents.id, { onDelete: 'cascade' }),
  jobId: text('job_id').notNull().unique(), // Bull queue job ID
  status: text('status').notNull().default('queued'), // 'queued' | 'processing' | 'completed' | 'failed'
  chunkedCount: integer('chunked_count'), // How many chunks created
  embeddedCount: integer('embedded_count'), // How many embeddings successful
  totalChunks: integer('total_chunks'), // Total expected chunks
  startedAt: timestamp('started_at', { withTimezone: true }),
  completedAt: timestamp('completed_at', { withTimezone: true }),
  errorMessage: text('error_message'),
  retryCount: integer('retry_count').notNull().default(0),
  maxRetries: integer('max_retries').notNull().default(3),
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),
  updatedAt: timestamp('updated_at', { withTimezone: true }).notNull().defaultNow(),
}, (table) => ({
  documentIdIdx: uniqueIndex().on(table.documentId),
  jobIdIdx: uniqueIndex().on(table.jobId),
  statusIdx: uniqueIndex().on(table.status),
}));

// ============= SEARCH QUERIES TABLE (Analytics) =============
export const searchQueries = pgTable('search_queries', {
  id: uuid('id').primaryKey().defaultRandom(),
  userId: uuid('user_id').notNull().references(() => users.id, { onDelete: 'cascade' }),
  query: text('query').notNull(),
  retrievedChunkCount: integer('retrieved_chunk_count').notNull(),
  answerGenerated: boolean('answer_generated').notNull().default(false),
  answerTokens: integer('answer_tokens'),
  executionTime: integer('execution_time'), // milliseconds
  relevanceFeedback: text('relevance_feedback'), // 'helpful' | 'not_helpful' | null
  createdAt: timestamp('created_at', { withTimezone: true }).notNull().defaultNow(),

INDEX STRATEGY:

BTREE Indexes (default):
- users.email (uniqueness + fast lookup)
- documents.status (filter by processing state)
- documentChunks.documentId (cascade queries)
- ingestionJobs.status (dashboard queries)
- searchQueries.createdAt (analytics time-series)

HNSW Index (vector search):
- embeddings.embedding (cosine distance, fast similarity search)
  This is critical for search performance. HNSW (Hierarchical Navigable Small World)
  provides ~10-100x speedup vs brute-force similarity on large datasets.

QUERY PATTERNS:

1. Semantic Search:
SELECT ce.chunk_id, dc.content, d.title, d.id as document_id,
       1 - (ce.embedding <=> $1::vector) as similarity,
       dc.metadata
FROM embeddings ce
JOIN document_chunks dc ON ce.chunk_id = dc.id
JOIN documents d ON dc.document_id = d.id
WHERE d.status = 'indexed'
ORDER BY similarity DESC
LIMIT $2;

2. Find document by ID with all chunks:
SELECT d.*, chunk FROM documents d
LEFT JOIN document_chunks chunk ON d.id = chunk.document_id
WHERE d.id = $1
ORDER BY chunk.chunk_index ASC;

3. Analytics - queries per hour:
SELECT DATE_TRUNC('hour', created_at) as hour, COUNT(*) as count
FROM search_queries
WHERE created_at >= NOW() - INTERVAL '24 hours'
GROUP BY hour
ORDER BY hour DESC;

MIDDLEWARE:

File: apps/api/src/middleware/auth.middleware.ts

import { Request, Response, NextFunction } from 'express';
import jwt from 'jsonwebtoken';

export interface AuthRequest extends Request {
  user?: {
    userId: string;
    email: string;
    role: 'user' | 'admin';
  };
}

export const authMiddleware = (req: AuthRequest, res: Response, next: NextFunction) => {
  const token = req.headers.authorization?.replace('Bearer ', '');
  
  if (!token) {
    return res.status(401).json({ error: 'Missing authorization token' });
  }
  
  try {
    const payload = jwt.verify(token, process.env.JWT_SECRET!) as any;
    req.user = {
      userId: payload.userId,
      email: payload.email,
      role: payload.role,
    };
    next();
  } catch (error) {
    return res.status(401).json({ error: 'Invalid or expired token' });
  }
};

export const requireRole = (role: 'admin' | 'user') => {
  return (req: AuthRequest, res: Response, next: NextFunction) => {
    if (!req.user) {
      return res.status(401).json({ error: 'Not authenticated' });
    }
    
    if (role === 'admin' && req.user.role !== 'admin') {
      return res.status(403).json({ error: 'Admin access required' });
    }
    
    next();
  };
};

import { db } from '../db/client';
import { embeddings, documentChunks, documents } from '../db/schema';
import { sql } from 'drizzle-orm';
import { embeddingService } from './embedding.service';

export interface SearchResult {
  chunkId: string;
  documentId: string;
  documentTitle: string;
  content: string;
  similarity: number;
  metadata?: {
    pageNumber?: number;
    section?: string;
    heading?: string;
  };
}

export async function semanticSearch(
  query: string,
  topK: number = 5,
): Promise<SearchResult[]> {
  // 1. Embed the query
  const queryEmbedding = await embeddingService.embed(query);
  
  // 2. Vector similarity search using pgvector
  const results = await db.execute(sql`
    SELECT 
      e.chunk_id,
      dc.document_id,
      dc.content,
      dc.metadata,
      d.title,
      1 - (e.embedding <=> ${queryEmbedding}::vector) as similarity
    FROM embeddings e
    JOIN document_chunks dc ON e.chunk_id = dc.id
    JOIN documents d ON dc.document_id = d.id
    WHERE d.status = 'indexed'
    ORDER BY similarity DESC
    LIMIT ${topK}
  `);
  
  return results.map((row: any) => ({
    chunkId: row.chunk_id,
    documentId: row.document_id,
    documentTitle: row.title,
    content: row.content,
    similarity: row.similarity,
    metadata: row.metadata,
  }));
}

import { openai } from 'openai';
import { SearchResult } from './search.service';
import { db } from '../db/client';
import { searchQueries } from '../db/schema';

export interface Citation {
  documentId: string;
  documentTitle: string;
  chunkId: string;
  content: string;
  pageNumber?: number;
  section?: string;
}

export interface RAGResponse {
  answer: string;
  citations: Citation[];
  retrievedChunks: SearchResult[];
  confidence: number;
}

export async function generateGroundedAnswer(
  query: string,
  retrievedChunks: SearchResult[],
  userId: string,
): Promise<RAGResponse> {
  const startTime = Date.now();
  
  // Build context from retrieved chunks
  const context = retrievedChunks
    .map((chunk, idx) => `[Source ${idx + 1}]\n${chunk.content}\n`)
    .join('\n---\n\n');
  
  const systemPrompt = `You are a helpful assistant. Answer the user's question based ONLY on the provided context.

Rules:
- If the context does not contain enough information to answer, say "I don't have enough information to answer this question."
- NEVER make up information or use knowledge outside the provided context.
- Always cite your sources using [Source N] format when referencing the context.
- Be concise, accurate, and factual.
- If unsure, acknowledge the uncertainty.`;

  const userMessage = `Context:\n${context}\n\nQuestion: ${query}`;

  // Call LLM
  const response = await openai.chat.completions.create({
    model: process.env.LLM_MODEL || 'gpt-4o-mini',
    system: systemPrompt,
    messages: [{ role: 'user', content: userMessage }],
    temperature: 0.2, // Low temperature for factuality
    max_tokens: 1024,
  });

  const answer = response.choices[0].message.content || '';
  
  // Parse citations from answer
  const citedSourceIndices = extractCitedSources(answer);
  
  const citations: Citation[] = citedSourceIndices
    .filter(idx => idx >= 0 && idx < retrievedChunks.length)
    .map(idx => {
      const chunk = retrievedChunks[idx];
      return {
        documentId: chunk.documentId,
        documentTitle: chunk.documentTitle,
        chunkId: chunk.chunkId,
        content: chunk.content,
        pageNumber: chunk.metadata?.pageNumber,
        section: chunk.metadata?.section,
      };
    });
  
  // Log for analytics
  const executionTime = Date.now() - startTime;
  await db.insert(searchQueries).values({
    userId,
    query,
    retrievedChunkCount: retrievedChunks.length,
    answerGenerated: true,
    answerTokens: response.usage?.completion_tokens || 0,
    executionTime,
  });
  
  return {
    answer,
    citations,
    retrievedChunks: retrievedChunks.slice(0, 3),
    confidence: citations.length > 0 ? 0.95 : 0.6,
  };
}

function extractCitedSources(answer: string): number[] {
  const regex = /\[Source (\d+)\]/g;
  const matches = [...answer.matchAll(regex)];
  return matches.map(m => parseInt(m[1]) - 1);
}

export const embeddingService = {
  async embed(text: string): Promise<number[]> {

      return embedOllama(text);
    }
    
    // Default: OpenAI
    const response = await openai.embeddings.create({
      model: process.env.EMBEDDING_MODEL || 'text-embedding-3-small',
      input: text,
    });
    
    return response.data[0].embedding;
  },

  async embedMany(texts: string[]): Promise<number[][]> {
    if (process.env.EMBEDDING_MODEL?.startsWith('ollama')) {
      return Promise.all(texts.map(t => embedOllama(t)));
    }
    
    // OpenAI batch embedding
    const response = await openai.embeddings.create({
      model: process.env.EMBEDDING_MODEL || 'text-embedding-3-small',
      input: texts,
    });
    
    return response.data
      .sort((a, b) => a.index - b.index)
      .map(item => item.embedding);
  },
};

async function embedOllama(text: string): Promise<number[]> {
  const url = new URL('/api/embed', process.env.OLLAMA_URL || 'http://localhost:11434');
  
  return new Promise((resolve, reject) => {
    const data = JSON.stringify({
      model: 'nomic-embed-text',
      prompt: text,
    });
    
    const req = https.request(
      { ...url, method: 'POST', headers: { 'Content-Type': 'application/json' } },
      (res) => {
        let body = '';
        res.on('data', chunk => (body += chunk));
        res.on('end', () => {
          try {
            resolve(JSON.parse(body).embedding);
          } catch (e) {
            reject(e);
          }
        });
      },
    );
    
    req.on('error', reject);
    req.write(data);
    req.end();
  });
}

      const file = req.file;
      if (!file) {
        return res.status(400).json({ error: 'No file provided' });
      }

      const checksum = crypto.createHash('sha256').update(file.buffer).digest('hex');

      await ingestionQueue.add(
        { documentId: doc.id, buffer: file.buffer },
        { attempts: 3, backoff: { type: 'exponential' } },
      );

export function useApi() {
  const { token } = useAuth();

  const api = {
    async fetch(url: string, options: RequestInit = {}) {
      const headers = {
        'Content-Type': 'application/json',
        ...options.headers,
      };

      if (token) {
        headers['Authorization'] = `Bearer ${token}`;
      }

      const response = await fetch(`${process.env.NEXT_PUBLIC_API_URL}${url}`, {
        ...options,
        headers,
      });

      if (!response.ok) {
        const error = await response.json().catch(() => ({}));
        throw new Error(error.error || `HTTP ${response.status}`);
      }

      return response.json();
    },

    get(url: string) {
      return this.fetch(url, { method: 'GET' });
    },

    post(url: string, body: any) {
      return this.fetch(url, {
        method: 'POST',
        body: JSON.stringify(body),
      });
    },

    put(url: string, body: any) {
      return this.fetch(url, {
        method: 'PUT',
        body: JSON.stringify(body),
      });
    },

    delete(url: string) {
      return this.fetch(url, { method: 'DELETE' });
    },
  };

  return { api };
}

'use client';

import React, { createContext, useState, useCallback, useEffect } from 'react';
import { useRouter } from 'next/navigation';

interface User {
  id: string;
  email: string;
  name: string;
  role: 'user' | 'admin';
}

export const AuthContext = createContext<{
  user: User | null;
  token: string | null;
  loading: boolean;
  login: (email: string, password: string) => Promise<void>;
  logout: () => void;
  isAuthenticated: boolean;
}>({
  user: null,
  token: null,
  loading: true,
  login: async () => {},
  logout: () => {},
  isAuthenticated: false,
});

export function AuthProvider({ children }: { children: React.ReactNode }) {
  const router = useRouter();
  const [user, setUser] = useState<User | null>(null);
  const [token, setToken] = useState<string | null>(null);
  const [loading, setLoading] = useState(true);

  // Load from localStorage on mount
  useEffect(() => {
    const stored = localStorage.getItem('auth');
    if (stored) {
      const { user, token } = JSON.parse(stored);
      setUser(user);
      setToken(token);
    }
    setLoading(false);
  }, []);

  const login = useCallback(async (email: string, password: string) => {
    const response = await fetch(`${process.env.NEXT_PUBLIC_API_URL}/api/auth/login`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ email, password }),
    });

    if (!response.ok) {
      throw new Error('Login failed');
    }

    const data = await response.json();
    setUser(data.user);
    setToken(data.accessToken);
    localStorage.setItem('auth', JSON.stringify({
      user: data.user,
      token: data.accessToken,
      refreshToken: data.refreshToken,
    }));

    router.push('/chat');
  }, [router]);

  const logout = useCallback(() => {
    setUser(null);
    setToken(null);
    localStorage.removeItem('auth');
    router.push('/login');
  }, [router]);

  return (
    <AuthContext.Provider value={{
      user,
      token,
      loading,
      login,
      logout,
      isAuthenticated: !!user,
    }}>
      {children}
    </AuthContext.Provider>
  );
}

CHUNKING STRATEGY:

Approach: Recursive Semantic Chunking with Overlap

Why this strategy?
- Preserves semantic boundaries (paragraphs, sections not cut mid-meaning)
- Overlap prevents query from falling between chunks
- Simple implementation (no LLM needed)
- Observable and deterministic
- Easily upgradeable to more sophisticated strategies later

File: apps/api/src/services/chunking.service.ts

import { encode } from 'js-tiktoken';

const gpt2Encoding = encode('cl100k_base'); // OpenAI token encoding

interface ChunkingOptions {
  maxChunkSize: number;    // tokens
  overlapSize: number;     // tokens
  separators: string[];    // fallback separators
}

interface DocumentChunk {
  content: string;
  tokens: number;
  startPosition: number;
  endPosition: number;
  metadata: {
    pageNumber?: number;
    section?: string;
    heading?: string;
  };
}

const DEFAULT_OPTIONS: ChunkingOptions = {
  maxChunkSize: 512,
  overlapSize: 50,
  separators: ['\n\n', '\n', '. ', ' ', ''],
};

export async function chunkDocument(
  content: string,
  fileType: 'pdf' | 'txt' | 'markdown',
  options: Partial<ChunkingOptions> = {},
): Promise<DocumentChunk[]> {
  const opts = { ...DEFAULT_OPTIONS, ...options };
  
  // 1. Extract text by file type
  let extracted: { text: string; pages?: Map<number, number[]> };
  
  if (fileType === 'pdf') {
    extracted = await extractTextFromPDF(content);
  } else {
    extracted = { text: content };
  }
  
  // 2. Split recursively
  const chunks = splitRecursive(extracted.text, opts);
  
  // 3. Enrich with metadata
  const enriched = chunks.map((chunk, idx) => {
    const pageNumber = extracted.pages
      ? findPageNumber(chunk.startPosition, extracted.pages)
      : undefined;
    
    return {
      ...chunk,
      metadata: {
        pageNumber,
        section: detectSection(chunk.content),
        heading: detectHeading(chunk.content),
      },
    };
  });
  
  return enriched;
}

function splitRecursive(
  text: string,
  options: ChunkingOptions,
  separatorIndex: number = 0,
): DocumentChunk[] {
  const separator = options.separators[separatorIndex] || '';
  const splitTexts = text.split(separator);
  
  const chunks: DocumentChunk[] = [];
  let currentChunk = '';
  let currentTokens = 0;
  let position = 0;
  
  for (let i = 0; i < splitTexts.length; i++) {
    const text = splitTexts[i];
    const tokens = gpt2Encoding(text).length;
    
    if (currentTokens + tokens > options.maxChunkSize) {
      // Current chunk is full, save it
      if (currentChunk) {
        chunks.push({
          content: currentChunk,
          tokens: currentTokens,
          startPosition: position - currentChunk.length,
          endPosition: position,
          metadata: {},
        });
        
        // Overlap: keep last 50 tokens
        const overlapEnd = Math.max(0, currentChunk.length - 50);
        position -= (currentChunk.length - overlapEnd);
        currentChunk = currentChunk.slice(overlapEnd);
        currentTokens = gpt2Encoding(currentChunk).length;
      }
    }
    
    currentChunk += text + (i < splitTexts.length - 1 ? separator : '');
    currentTokens = gpt2Encoding(currentChunk).length;
    position += text.length + separator.length;
  }
  
  // Add final chunk
  if (currentChunk) {
    chunks.push({
      content: currentChunk,
      tokens: currentTokens,
      startPosition: position - currentChunk.length,
      endPosition: position,
      metadata: {},
    });
  }
  
  // If chunks still too large and separators left, recurse
  if (chunks.some(c => c.tokens > options.maxChunkSize) && separatorIndex < options.separators.length - 1) {
    return splitRecursive(text, options, separatorIndex + 1);
  }
  
  return chunks;
}

function detectSection(text: string): string | undefined {
  // Look for common section markers
  const sectionMatch = text.match(/^#{1,6}\s+(.+?)$/m);
  return sectionMatch ? sectionMatch[1] : undefined;
}

function detectHeading(text: string): string | undefined {
  const lines = text.split('\n');
  for (const line of lines) {
    if (line.match(/^#{1,3}\s+/)) {
      return line.replace(/^#+\s+/, '');
    }
  }
  return undefined;
}

async function extractTextFromPDF(buffer: Buffer): Promise<any> {
  // Use pdfjs-dist or pdf-parse
  // Returns { text, pages: Map<pageNumber, [startPos, endPos]> }
  const pdfParse = require('pdf-parse');
  const data = await pdfParse(buffer);
  return {
    text: data.text,
    pages: new Map(data.pages.map((p: any, idx: number) => [idx + 1, [p.startPosition, p.endPosition]])),
  };
}

import { Queue, Worker, QueueScheduler } from 'bullmq';
import { Redis } from 'ioredis';
import { db } from '../db/client';
import { ingestionJobs, documents } from '../db/schema';
import { eq } from 'drizzle-orm';
import { chunkDocument } from '../services/chunking.service';
import { embeddingService } from '../services/embedding.service';
import { documentRepository } from '../repositories/document.repository';

const redis = new Redis({
  host: process.env.REDIS_HOST || 'localhost',
  port: parseInt(process.env.REDIS_PORT || '6379'),
});

export const ingestionQueue = new Queue('document-ingestion', { connection: redis });

// ============= WORKER =============
const worker = new Worker(
  'document-ingestion',
  async (job) => {
    const { documentId } = job.data;
    
    console.log(`Processing ingestion job for document ${documentId}`);
    
    try {
      // Update status to processing
      await db.update(ingestionJobs)
        .set({ status: 'processing', startedAt: new Date() })
        .where(eq(ingestionJobs.documentId, documentId));
      
      // Fetch document with content
      const doc = await documentRepository.findById(documentId);
      if (!doc) throw new Error('Document not found');
      
      // 1. Chunk the document
      const chunks = await chunkDocument(
        doc.content,
        doc.fileType as 'pdf' | 'txt' | 'markdown',
        { maxChunkSize: 512, overlapSize: 50 },
      );
      
      console.log(`Created ${chunks.length} chunks for document ${documentId}`);
      
      // 2. Save chunks to database
      const savedChunks = await documentRepository.createChunks(
        chunks.map((chunk, idx) => ({
          documentId,
          chunkIndex: idx,
          content: chunk.content,
          tokens: chunk.tokens,
          startPosition: chunk.startPosition,
          endPosition: chunk.endPosition,
          metadata: chunk.metadata,
        })),
      );
      
      // 3. Generate embeddings (batch)
      const embeddings = await embeddingService.embedMany(
        chunks.map(c => c.content),
      );
      
      console.log(`Generated ${embeddings.length} embeddings for document ${documentId}`);
      
      // 4. Store embeddings in database
      await db.insert(embeddings as any).values(
        savedChunks.map((chunk, idx) => ({
          chunkId: chunk.id,
          embedding: embeddings[idx],
          modelName: process.env.EMBEDDING_MODEL || 'text-embedding-3-small',
          modelVersion: '1.0',
        })),
      );
      
      // 5. Update document status to indexed
      await documentRepository.updateStatus(documentId, 'indexed');
      
      // 6. Update ingestion job
      await db.update(ingestionJobs)
        .set({
          status: 'completed',
          chunkedCount: chunks.length,
          embeddedCount: embeddings.length,
          totalChunks: chunks.length,
          completedAt: new Date(),
        })
        .where(eq(ingestionJobs.documentId, documentId));
      
      console.log(`Successfully indexed document ${documentId}`);
      return { success: true, chunksCreated: chunks.length };
      
    } catch (error) {
      console.error(`Ingestion failed for document ${documentId}:`, error);
      
      // Update document status to failed
      await documentRepository.updateStatus(documentId, 'failed');
      
      // Update ingestion job
      await db.update(ingestionJobs)
        .set({
          status: 'failed',
          errorMessage: error instanceof Error ? error.message : 'Unknown error',
          retryCount: (job.attemptsMade || 0),
        })
        .where(eq(ingestionJobs.documentId, documentId));
      
      throw error;
    }
  },
  { connection: redis, concurrency: 2 }, // Process 2 jobs concurrently
);

// ============= ERROR HANDLING =============
worker.on('completed', (job) => {
  console.log(`Job ${job.id} completed`);
});

worker.on('failed', (job, err) => {

9. AUTHENTICATION & AUTHORIZATION
================================================================================

JWT STRATEGY:

Flow:
1. User logs in with email/password
2. Server issues short-lived access token (15 minutes)
3. Server issues long-lived refresh token (7 days), stored in DB
4. Client stores both in localStorage
5. Client includes access token in Authorization header
6. When access token expires, client uses refresh token to get new access token
7. If refresh token expires, user must log in again

File: apps/api/src/routes/auth.routes.ts

import { Router, Response } from 'express';
import { AuthRequest } from '../middleware/auth.middleware';
import jwt from 'jsonwebtoken';
import bcrypt from 'bcrypt';
import { z } from 'zod';
import { db } from '../db/client';
import { users, sessions } from '../db/schema';
import { eq } from 'drizzle-orm';

const router = Router();

const loginSchema = z.object({
  email: z.string().email(),
  password: z.string().min(6),
});

const registerSchema = z.object({
  email: z.string().email(),
  password: z.string().min(6),
  name: z.string().min(1),
});

router.post('/login', async (req: AuthRequest, res: Response) => {
  try {
    const { email, password } = loginSchema.parse(req.body);
    
    // Find user
    const user = await db.query.users.findFirst({
      where: eq(users.email, email),
    });
    
    if (!user || !await bcrypt.compare(password, user.hashedPassword)) {
      return res.status(401).json({ error: 'Invalid credentials' });
    }
    
    // Generate tokens
    const accessToken = jwt.sign(
      { userId: user.id, email: user.email, role: user.role },
      process.env.JWT_SECRET!,
      { expiresIn: '15m' },
    );
    
    const refreshToken = jwt.sign(
      { userId: user.id },
      process.env.JWT_REFRESH_SECRET!,
      { expiresIn: '7d' },
    );
    
    // Store refresh token
    await db.insert(sessions).values({
      userId: user.id,
      refreshToken,
      expiresAt: new Date(Date.now() + 7 * 24 * 60 * 60 * 1000),
    });
    
    res.json({
      accessToken,
      refreshToken,
      user: {
        id: user.id,
        email: user.email,
        name: user.name,
        role: user.role,
      },
    });
  } catch (error) {
    console.error('Login error:', error);
    res.status(400).json({ error: 'Login failed' });
  }
});

router.post('/refresh', async (req: AuthRequest, res: Response) => {
  try {
    const { refreshToken } = req.body;
    
    if (!refreshToken) {
      return res.status(401).json({ error: 'Missing refresh token' });
    }
    
    // Verify refresh token
    const payload = jwt.verify(refreshToken, process.env.JWT_REFRESH_SECRET!) as any;
    
    // Check if session exists and not expired
    const session = await db.query.sessions.findFirst({
      where: eq(sessions.refreshToken, refreshToken),
    });
    
    if (!session || new Date() > session.expiresAt) {
      return res.status(401).json({ error: 'Refresh token expired' });
    }
    
    // Get updated user info
    const user = await db.query.users.findFirst({
      where: eq(users.id, payload.userId),
    });
    
    if (!user || !user.isActive) {
      return res.status(401).json({ error: 'User not found or inactive' });
    }
    
    // Issue new access token
    const newAccessToken = jwt.sign(
      { userId: user.id, email: user.email, role: user.role },
      process.env.JWT_SECRET!,
      { expiresIn: '15m' },
    );
    
    res.json({ accessToken: newAccessToken });
  } catch (error) {
    res.status(401).json({ error: 'Token refresh failed' });
  }
});

router.post('/register', async (req: AuthRequest, res: Response) => {
  try {
    const { email, password, name } = registerSchema.parse(req.body);
    
    // Check if user exists
    const existing = await db.query.users.findFirst({
      where: eq(users.email, email),
    });
    
    if (existing) {
      return res.status(400).json({ error: 'Email already registered' });
    }
    
    // Hash password
    const hashedPassword = await bcrypt.hash(password, 10);
    
    // Create user
    const [newUser] = await db.insert(users).values({
      email,
      hashedPassword,
      name,
      role: 'user', // Default to user role
    }).returning();
    
    res.json({
      message: 'Registration successful',
      user: { id: newUser.id, email: newUser.email, name: newUser.name },
    });
  } catch (error) {
    console.error('Register error:', error);
    res.status(400).json({ error: 'Registration failed' });
  }
});

  try {
    const { refreshToken } = req.body;
    
    if (refreshToken) {
      // Delete the session
      await db.delete(sessions).where(eq(sessions.refreshToken, refreshToken));
    }
    
    res.json({ message: 'Logged out' });
  } catch (error) {
    res.status(500).json({ error: 'Logout failed' });
  }

function formatSearchResult(result: any): string {
  const { answer, citations, retrievedChunks } = result;

  let formatted = `Answer:\n${answer}\n\n`;

  if (citations && citations.length > 0) {
    formatted += `Sources:\n`;
    citations.forEach((citation: any, idx: number) => {
      formatted += `${idx + 1}. "${citation.documentTitle}"`;
      if (citation.pageNumber) {
        formatted += ` (page ${citation.pageNumber})`;
      }
      formatted += `\n`;
    });
  }

  if (retrievedChunks && retrievedChunks.length > 0) {
    formatted += `\nRelevant excerpts:\n`;
    retrievedChunks.forEach((chunk: any, idx: number) => {
      formatted += `[${idx + 1}] ${chunk.documentTitle}:\n${chunk.content.substring(0, 200)}...\n\n`;
    });
  }

  return formatted;
}

14. KEY DESIGN DECISIONS
================================================================================

TECHNOLOGY CHOICES:

1. PostgreSQL + Pgvector (vs. Separate Vector DB)
   Decision: PostgreSQL + pgvector extension
   Why: 
   - Single database reduces operational complexity
   - ACID compliance for reliability
   - Enables hybrid search (future)
   - Cost-effective (no separate service)
   Tradeoff: Slightly less performance than specialized vector DBs at massive scale (100M+ vectors)
   Upgrade path: Switch to Qdrant/Pinecone if needed later

2. Express.js (vs. Full Next.js + Fastify)
   Decision: Express.js for backend, Next.js for frontend
   Why:
   - Clear separation of concerns
   - Express is industry standard, large ecosystem
   - Easier testing and middleware composition
   - Type-safe with TypeScript
   Tradeoff: Slightly more boilerplate than full Next.js monolith
   Benefit: Allows MCP server to run independently

3. Drizzle ORM (vs. Prisma, TypeORM, Sequelize)
   Decision: Drizzle ORM
   Why:
   - Type-safe SQL
   - Migrations in TypeScript (not separate SQL files)
   - Lightweight (no code generation)
   - Excellent DX
   Tradeoff: Smaller ecosystem than Prisma
   Benefit: Zero runtime overhead, perfect for serverless

4. Bull/BullMQ (vs. Temporal, AWS SQS, Celery)
   Decision: Bull with Redis
   Why:
   - Handles reliable job processing with retries
   - Observable progress (Bull Board)
   - Perfect for medium-scale (thousands of jobs/day)
   - Built-in retry and backoff logic
   Tradeoff: Not ideal for millions of jobs/day
   Upgrade path: Switch to Temporal or AWS if scaling massively

5. Recursive Semantic Chunking (vs. LLM-based, Sliding Window)
   Decision: Recursive semantic chunking with overlap
   Why:
   - Preserves semantic boundaries (paragraphs, sections)
   - Deterministic and observable
   - No LLM calls needed (saves cost and latency)
   - Overlap prevents queries falling between chunks
   Tradeoff: May not be optimal for all domains
   Upgrade path: Implement LLM-based chunking later for specialized cases

6. OpenAI Embeddings (vs. Local Ollama, Hugging Face)
   Decision: OpenAI (configurable, defaults to text-embedding-3-small)
   Why:
   - High quality, well-tested
   - Cost-effective (cheap at scale)
   - .env configurable for easy switching
   Alternative: Ollama for offline/privacy
   Benefit: Simple to start, can swap embedding model anytime

7. JWT + Refresh Tokens (vs. Sessions, OAuth2)
   Decision: JWT access + refresh tokens
   Why:
   - Stateless (scales horizontally)
   - Industry standard
   - Refresh tokens stored in DB for revocation
   Bonus: OIDC ready (OAuth2) for future enterprise use

8. Tailwind CSS (vs. Styled Components, CSS Modules)
   Decision: Tailwind CSS
   Why:
   - Utility-first, no context switching
   - Small bundle size
   - Great for responsive design
   - Industry standard
   Tradeoff: Markup-heavy at first glance
   Benefit: Consistent design system built-in
