# Artist Onboarding & Music Release Checklist

## Overview

Executing a successful music release requires coordinated workflow planning across recording engineering, metadata registration, distribution delivery, playlist pitching, and press campaigns. This operational checklist outlines the 6-week release timeline.

## Release Rollout Timeline (6 Weeks to Release Day)

```
[ T-6 Weeks ] Prepare Uncompressed Audio Masters & Final Artwork
[ T-4 Weeks ] Ingest via Distributor & Register ISRC / ISWC Codes
[ T-3 Weeks ] Submit Spotify for Artists Editorial Playlist Pitch
[ T-2 Weeks ] Launch Pre-Save Campaigns & Press Kit Distribution
[ Release Day ] Monitor DSP Ingestion & Execute Social Launch
[ Post-Release ] Submit Setlists to PROs & Track Streaming Analytics
```

### 1. Six Weeks Before Release (T-6 Weeks)
- [ ] Finalize stereo 24-bit / 44.1 kHz WAV master files and verify true peak ceiling (-1.0 dBTP).
- [ ] Create 3000 x 3000 pixel high-resolution cover artwork complying with DSP specs.
- [ ] Confirm legal clearance agreements for all samples, interpolations, feature features, and producer splits.

### 2. Four Weeks Before Release (T-4 Weeks)
- [ ] Upload release package to digital distributor (DistroKid, TuneCore, AWAL).
- [ ] Input complete metadata: ISRC codes, primary/featured artist IDs, explicit tags, and full legal songwriter names.
- [ ] Register musical composition with PROs (ASCAP, BMI, PRS) to obtain ISWC codes.
- [ ] Submit mechanical licensing registration to the Mechanical Licensing Collective (MLC).

### 3. Three Weeks Before Release (T-3 Weeks)
- [ ] Log into Spotify for Artists portal and submit the track for **Editorial Playlist Consideration** (Pitching must occur at least 7 days before release date; 21 days recommended).
- [ ] Pitch Apple Music for Artists and Amazon Music for Artists featured placement banners.
- [ ] Provide lyric transcriptions to Musixmatch and Genius for synced lyrics integration on Instagram/Spotify.

### 4. Two Weeks Before Release (T-2 Weeks)
- [ ] Generate smart pre-save links (Feature.fm, Linkfire, ToneDen).
- [ ] Send press releases, EPK (Electronic Press Kit), and private Soundcloud/Box preview links to music journalists, blogs, and radio DJs.
- [ ] Deliver Canvas videos (9:16 vertical short looping video files, 3-8 seconds) for Spotify Canvas upload.

### 5. Release Day (T-0)
- [ ] Verify live release links on Spotify, Apple Music, YouTube Music, and Tidal.
- [ ] Share smart links across artist social channels (Instagram, TikTok, YouTube Shorts).
- [ ] Pin track link to top of Spotify artist profile.

### 6. Post-Release Follow-Up
- [ ] Review 7-day streaming performance metrics in Spotify for Artists & Apple Music for Artists dashboards.
- [ ] Register setlists with PRO portals for any live show performances following release.
- [ ] Archive all final master files, stems, and metadata documentation in secure cloud storage.
