# Music Licensing and Sync Synchronization Guide

## Overview

Music synchronization ("sync") licensing permits the integration of copyrighted musical works with visual media, including feature films, television shows, video games, commercial advertisements, and online digital media.

## Dual License Requirement for Sync

Securing a valid sync placement requires obtaining **two separate licenses** unless the master and publishing rights are owned by the same entity:

1. **Master Use License**: Granted by the owner of the sound recording (typically the record label or independent artist) to use the specific audio recording.
2. **Synchronization (Sync) License**: Granted by the music publisher or songwriter(s) to use the underlying composition (lyrics and melody).

```
                      +-----------------------------+
                      |   Visual Media Project      |
                      |   (Film/TV/Game/Commercial) |
                      +--------------+--------------+
                                     |
               +---------------------+---------------------+
               |                                           |
               v                                           v
    +--------------------+                       +--------------------+
    | Master Use License |                       |    Sync License    |
    | (Record Label)     |                       | (Music Publisher)  |
    +--------------------+                       +--------------------+
```

## Key Contractual Terms in Sync Agreements

- **Media Rights / Scope**: Defines where the visual work will be broadcast (e.g., All Media, Linear TV Only, SVOD/Streaming, Social Media Digital Ads).
- **Territory**: Geographic scope of usage rights (e.g., Worldwide, North America, Universe).
- **Term Duration**: Length of time the license is active (e.g., 1 Year, 5 Years, Perpetuity).
- **MFN (Most Favored Nations) Clause**: Guarantees that if another track in the same visual project receives a higher licensing fee or more favorable terms, this license fee will automatically match that higher figure.
- **In-Context vs. Out-of-Context Rights**:
  - *In-Context*: Allows the music to be used in promotional trailers exactly as it appears within the visual scene.
  - *Out-of-Context*: Requires an additional fee if the track is used in film trailers or marketing materials separately from the scene itself.

## Commercial Advertising Sync Rates (2026 Benchmarks)

Licensing fees for commercial placements depend heavily on brand stature, campaign duration, and media buy:

| Campaign Type | Scope & Territory | Typical Fee Range (Master + Publishing) |
|---|---|---|
| National TV Campaign | 1 Year, Worldwide | $75,000 - $250,000+ |
| Regional TV / Digital | 6 Months, North America | $15,000 - $45,000 |
| Social Media / Influencer | 3 Months, Digital Only | $3,000 - $12,000 |
| AAA Video Game Placement | Perpetuity, Worldwide | $20,000 - $60,000 |
| Indie Film Placement | Festival Rights Only | $500 - $2,500 |

## Cue Sheets and Public Performance Royalty Collection

When a sync placement airs on broadcast television, cable, or cinema, the production company must file a **Cue Sheet** with PROs (such as ASCAP, BMI, PRS). The cue sheet contains:
- Film/Episode Title & Production Company
- Track Title, ISRC, ISWC, Songwriters, Publishers, and PRO affiliations
- Precise duration (minutes & seconds) and usage type (Background Vocal, Background Instrumental, Visual Instrumental, Theme Song)

PROs use cue sheets to pay secondary backend public performance royalties directly to songwriters and publishers every quarter.
