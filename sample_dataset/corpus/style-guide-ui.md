# UI Style Guide

Buttons: a playable has exactly one primary CTA visible at a time. The CTA uses the client brand color; if contrast against the background is below 4.5:1, add the standard dark scrim behind it.

Text: system font stack only; embedded fonts are allowed just for the logo and the CTA label, subsetted to the used glyphs.

Progress: any playable longer than 20 seconds must show progress (bar, counter or steps). Fail states must always offer retry within one tap.

End card: logo, one line of copy, one CTA. Nothing else. Store badges are added by the network wrapper, never baked into the creative.
